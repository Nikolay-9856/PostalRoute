# Почтовый маршрут · ПП.ПМ.13 · вариант 12

Курьер разносит письма: письмо нужно сначала поднять, затем доставить в ящик с тем же номером; второе письмо взять нельзя, неверный ящик отнимает попытку. Учебный выпуск 1.0.0 по производственной практике ПП.ПМ.13 «Оформление игрового продукта», Университет «Синергия».

## Запуск
1. Unity Hub → Add → папка репозитория. Версия редактора: **Unity 6.6 (6000.6.2f1)**.
2. При первом открытии `ReleaseSetup` (Assets/Editor) создаёт сцену `Assets/Scenes/Main.unity`, добавляет её в Build Profiles и записывает в Player Settings название «Почтовый маршрут» и версию **1.0.0**. Повторно — меню **Почтовый маршрут → Применить настройки выпуска**.
3. Откройте `Assets/Scenes/Main.unity` и нажмите Play. Игру создаёт `GameBootstrap` — объекты в сцену вручную не добавляются.
4. Проверка размеров: вкладка Game → «+» → Fixed Resolution 1280×720, 1440×720, 1024×768.

## Ориентация и ввод
- Ориентация: **альбомная** (16:9, 18:9, 4:3). Портретный режим не поддерживается.
- Управление: экранные стрелки (мышь/касание) или W A S D / стрелки; Esc — пауза; F9 — снимок кадра.

## Данные игрока
PlayerPrefs, префикс `PP12.Postal.v1.` (открытые уровни, рекорды, громкость). Просмотр обучения — отдельный ключ `PP13.Postal.Tutorial.v1`. Для проверки «нового пользователя» меняйте только ключ обучения; не вызывайте `PlayerPrefs.DeleteAll`.

## Учебные переключатели
- `Canvas → SafeArea → Simulate Insets` (во время Play) — имитация вырезов 8% / 5%. Для выпуска выключено.
- `PostalRoute → GameManager → Hud Shows Address` — строка «В сумке» в HUD (выключить только для снимка «до исправления»).

## Ограничения выпуска
- Проверка выполнялась в Game View редактора; запуск на телефоне и реальные вырезы экрана не проверялись.
- Исполняемая сборка прикладывается через Releases хостинга только при установленном модуле платформы; иначе сдаётся Unity-проект.
- Сетевых функций, рекламы и облачных сохранений нет.
