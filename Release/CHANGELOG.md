# Список изменений

## 1.0.0 — выпуск по ПП.ПМ.13
Новое в этой практике:
- SafeAreaPanel: интерфейс размещён в безопасной области (SafeArea → SafeContent, макет 1280×720), учебная имитация вырезов Simulate Insets.
- WorldBuilder: подстройка ортографической камеры под 16:9, 18:9 и 4:3 — поле района не обрезается.
- TutorialController: три подсказки (управление, письмо и ящик, ошибка и завершение), «Далее», «Пропустить», повтор через «Как играть»; отдельный ключ PP13.Postal.Tutorial.v1.
- PanelTransition: плавное появление панелей за 0,18 с на unscaledDeltaTime, в том числе на паузе; кнопки недоступны до конца появления; скрытые панели выключаются и не перехватывают ввод.
- AboutPanel: экран «Об игре» с названием, версией из Player Settings, авторством и источниками ресурсов.
- ScreenshotCapture: сохранение кадра Game View в PNG по F9.
- HUD: строка «В сумке: письмо №N» и конверт с номером над курьером (исправление по итогам проверки понятности).
- ReleaseSetup (Editor): название продукта, версия 1.0.0, альбомная ориентация, сцена Main в профиле сборки.
- Папка Release: описания, инструкция, CREDITS, иконка, рекламное изображение, кадры, раскадровка демонстрации.

Сохранено из ПП.ПМ.12 без изменения правил: три уровня, особое правило доставки, победа и поражение, пауза, настройка громкости, локальный прогресс (префикс PP12.Postal.v1.).

## Известные ограничения
- Проверено в Game View редактора; реальный телефон и вырезы экрана не проверялись (безопасная область проверена имитацией).
- Портретная ориентация не поддерживается.
- Исполняемая сборка прикладывается только при наличии установленного модуля платформы.
